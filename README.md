# 🤖 Simple Python Chatbot

Hi, I'm Aryan Sharma 👋

This is a very basic chatbot I made in Python. It's not fancy and it doesn't use any AI, but it was a fun way to practice the basics and see a program actually "talk back" to me.

## What it does

You type something, and the chatbot replies. That's it. Right now it understands three things:

| You type | Chatbot says |
|----------|--------------|
| `hello` | Hi! How can i help you? |
| `how are you` | I'm fine, thanks! |
| `bye` | Goodbye! (and the program ends) |

If you type anything else, it politely says it doesn't understand. Honestly, that happens a lot, because it only knows those three phrases for now 😅

It also doesn't care about capital letters, so `Hello`, `HELLO` and `hello` all work the same.

## How to run it

1. Make sure you have Python 3 installed.
2. Download or clone this repo:

git clone <https://github.com/AryanSharma1105/Codealpha_Basic_Chatbot.git>

3. Open the folder in your terminal and run:

basic_chatbot.py

4. Start chatting. Type `bye` when you want to stop.

## Example chat

Chatbot: Hello! I am a chatbot.
Chatbot: Type ‘bye’ to end the conversation.
You: Hello
Chatbot: Hi!
Chatbot: How can i help you?
You: how are you
Chatbot: I’m fine, thanks!
You: what’s your name
Chatbot: Sorry, I don’t understand that.
You: bye
Chatbot: Goodbye!


## What I practiced

- Writing a function and calling it
- Using a `while True` loop to keep the program running
- Taking input with `input()`
- Using `.lower()` so capital letters don't break things
- `if / elif / else` for deciding what to reply
- Using `break` to exit the loop
